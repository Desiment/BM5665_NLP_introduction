
## Introduction to Language Modeling
Based on https://lena-voita.github.io/nlp_course.html

**Goal**: Predict the next word in a sequence given previous words. Formally, compute the probability of a sequence:  

$$P(w_1, w_2, ..., w_T) = \prod_{t=1}^T P(w_t \mid w_{t-1}, \ldots w_1)$$

**Applications**: Machine translation, speech recognition, text generation.


## N-gramm Models
### Key Idea
Use the **Markov assumption**: approximate the probability using only the last \(n-1\) words:  

$$P(w_t \mid  w_{t-1}, \ldots, w_1) = P(w_t \mid w_{t-1} \ldots w_{t-n+1})$$

Under Markov assumption one can write MLE-estiamtion of conditional probabilities. If $\text{Count}(w_1, \ldots w_n)$ denotes
occurences of sequence $w_1, \ldots, w_n$ inside traning dataset, we can estimate conditional probabilities as

$$\hat{P}(w_t \mid  w_{t-1}, \ldots, w_1) =  \frac{\text{Count}(w_1, \ldots w_t)}{\text{Count}(w_1, \ldots w_{t-1})}$$

**Example** (trigram):  

$$\hat{P}(\text{"sat"} \mid \text{"the cat"}) = \frac{\text{Count("the cat sat")}}{\text{Count("the cat")}}$$

### Challenges
- **Sparsity**: Many n-grams never appear in training data.
- **Storage**: Large vocabluary size and $n$ requires massive memory for counts.

### Evaluation
- **Negative likehood** (cross-entropy loss):  
  $$\text{NLL} = -\sum_{t=1}^T \log \hat{P}(w_t \mid w_{t-n+1}, ..., w_{t-1})$$

- **Perplexity**: Measure of model uncertainty:  
  $$\text{Perplexity} = \exp\left(-\frac{1}{T} \sum_{t=1}^T \log \hat{P}(w_t \mid w_{t-n+1}, ..., w_{t-1})\right)$$


### Model smoothing.
In order to avoid probabilites 0 (caused by fact that sequence $(w_1, \ldots w_t)$ never occured in dataset) which lead
to undefined losses and division by 0 (when sequence $(w_1, \ldots w_{t-1})$ never occured in dataset) in estimating probabilities
one can use "fake counts" instead, a.k.a smoothing. Two most popular variants are
- **Laplace**: Add $\alpha$ to all counts.
- **Kneser-Ney**: Discount frequent words and prioritize continuation probability.  


## Neural Language Models

### Architecture Overview
1. **Embedding Layer**: Maps words to dense vectors.  
2. **Context Encoder**: Processes input sequence (e.g., RNN, CNN, Transformer).  
3. **Output Layer**: Computes word probabilities via softmax.  

### Advantages over N-grams
- **Generalization**: Similar words share embeddings (e.g., "dog" vs. "puppy").  
- **Long-Range Context**: Models like RNNs/Transformers capture dependencies beyond fixed \(n\).  

### Training
- **Loss**: Cross-entropy between predicted and true next-word distribution.  
- **Teacher Forcing**: Feed true previous words during training.

## Word Embeddings
Machine learning models require **vector representations** of words (embeddings) to process text. Unlike humans, models cannot directly interpret raw text.

### Representing Words as Discrete Symbols: One-Hot Vectors
- **Definition**: Each word is a sparse vector with `1` at its index in the vocabulary and `0` elsewhere.
- **Limitations**:
  - High dimensionality (vocabulary size = vector length).
  - No semantic relationships (e.g., "cat" and "dog" are as dissimilar as "cat" and "table") :cite[1].

### Distributional Semantics. The Distributional Hypothesis
- **Key Idea**: "You shall know a word by the company it keeps" (Firth, 1957).
  - **Distributional Hypothesis**: Words appearing in similar contexts share similar meanings (e.g., "tezgüino" ≈ "wine" based on usage)
- **Goal**: Embeddings should encode contextual information.

#### Count-Based Methods
General Approach:
1. Build a **word-context matrix** (e.g., co-occurrence counts).
2. Reduce dimensionality (e.g., via SVD) to capture meaningful patterns.
Some techniques
1. **Co-Occurrence Counts**:
   - Context = fixed window around a word.
   - Example: The HAL model (1996) uses window-based counts
2. **Positive PMI (PPMI)**:
   - Measures association between words and contexts:  
     $$\text{PPMI}(w, c) = \max\left(\log\frac{P(w,c)}{P(w)P(c)}, 0\right)$$
   - State-of-the-art for pre-neural methods
3. **Latent Semantic Analysis (LSA)**:
   - Applies SVD to term-document matrices (e.g., TF-IDF).
   - Captures document-level topic similarities

#### Prediction-Based Methods: Word2Vec
- **Goal**: Learn embeddings by predicting context words given a central word (or vice versa).
- **Architectures**:
  - **Skip-Gram**: Predict context words from a central word.
  - **CBOW**: Predict the central word from context words :cite[1]:cite[5].

![Word2Vec Architectures](https://lena-voita.github.io/resources/lectures/word_emb/w2v/cbow_skip-min.png)

Training Objective
- **Negative Log-Likelihood Loss**:

$$J(\theta) = -\frac{1}{T} \sum_{t=1}^T \sum_{-m \leq j \leq m, j \neq 0} \log P(w_{t+j} | w_t; \theta)$$

- **Probability Calculation**:
  - \(v_c\): Central word embedding.
  - \(u_o\): Context word embedding

$$P(o | c) = \frac{\exp(u_o^T v_c)}{\sum_{w \in V} \exp(u_w^T v_c)}$$
  
Training Process
1. Slide a window over the corpus.
2. For each central word, compute context probabilities.
3. Update embeddings via gradient descent.
